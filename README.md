Hearth Budget — a household budget site that adds up. Track income, spending, budgets and savings goals for a real household month, with working charts, an add/delete transaction ledger, editable budgets, savings-goal contributions and plain-English insights. Everything runs in the browser from static files; nothing is uploaded.

## Run it

```sh
cd app && python3 -m http.server 8000
```

Then open http://localhost:8000 in a desktop browser or on a phone.
